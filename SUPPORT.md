# Support Lore

Lore is free to use. Donations are optional and support development, maintenance and the details that make the app useful. Everyone gets the same features.

## Donations

The maintainer's GitHub Sponsors application has been submitted and is awaiting GitHub approval. The donation link will be enabled here and in the app once the profile is public. No payment link is presented as active before that.

## Other ways to help

- Share Lore with a developer who could use it.
- [Report a bug or suggest an improvement](https://github.com/wassimkanze/Lore/issues).
- Help with code, documentation, testing or design. See [CONTRIBUTING.md](CONTRIBUTING.md).

When reporting an issue, use synthetic examples and remove private project names or paths from screenshots. Please do not upload agent conversations, credentials or your Lore database.
